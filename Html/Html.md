HTML é a linguagem base da web. Ele define a estrutura das páginas.

## 📌 1. O que é HTML
- HTML = HyperText Markup Language
- Linguagem de marcação (não é programação)
- Cria a estrutura da página

---

## 📌 2. Estrutura básica

```html id="html-estrutura-basica"
<!DOCTYPE html>
<html>
<head>
    <title>Minha Página</title>
</head>
<body>
    <h1>Olá Mundo</h1>
</body>
</html>
