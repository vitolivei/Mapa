# ⚡ JavaScript

- [👉 ⬅ Voltar para HOME](../index.html)

> Linguagem usada para interatividade, lógica e manipulação do HTML no navegador.

---

# 🧠 1. A

## 1.1 Array — criar listas de dados
- `let lista = [1,2,3]`
- `push()` adiciona item
- `pop()` remove último
- `map()` transforma valores
- `filter()` filtra itens

👉 O que faz:
- armazena e manipula conjuntos de dados

---

## 1.2 Arrow Function — criar funções curtas
- `const soma = (a,b) => a + b`

👉 O que faz:
- reduz código de funções simples
- melhora leitura

---

# 🧠 2. D

## 2.1 DOM — acessar elementos HTML
- `document.getElementById("id")`
- `document.querySelector(".classe")`
- `innerHTML` altera conteúdo
- `style` altera CSS

👉 O que faz:
- conecta JS com HTML
- permite alterar página em tempo real

---

## 2.2 Debug — identificar erros
- `console.log()`
- DevTools (F12)
- breakpoints

👉 O que faz:
- ajuda a encontrar erros no código

---

# 🧠 3. E

## 3.1 Event — ações do usuário
- click
- keydown
- mouseover
- submit

👉 O que faz:
- detecta interação do usuário

---

## 3.2 addEventListener — ouvir eventos
- `element.addEventListener("click", funcao)`

👉 O que faz:
- executa código quando evento acontece

---

# 🧠 4. F

## 4.1 Function — criar funções
- `function nome() {}`
- `return valor`

👉 O que faz:
- executa tarefas reutilizáveis

---

# 🧠 5. L

## 5.1 Loop — repetição
- `for`
- `while`
- `forEach`

👉 O que faz:
- repete ações automaticamente

---

# 🧠 6. O

## 6.1 Object — estrutura de dados
- `let pessoa = {nome:"João", idade:20}`

👉 O que faz:
- organiza informações em pares chave/valor

---

# 🧠 7. S

## 7.1 String — manipular texto
- `length`
- `toUpperCase()`
- `slice()`

👉 O que faz:
- trabalha com textos

---

## 7.2 Storage — salvar dados no navegador
- `localStorage.setItem()`
- `localStorage.getItem()`
- `sessionStorage`

👉 O que faz:
- guarda dados no navegador

# 🧠 8. V

## 8.1 Variable — armazenar valores
- `let`
- `const`
- `var`

👉 O que faz:
- guarda dados para uso no código
